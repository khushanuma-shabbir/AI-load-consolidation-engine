HOW TO USE
================================================================================

METHOD 1: STREAMLIT DASHBOARD (RECOMMENDED)
-------------------------------------------
1. Start the dashboard:
   streamlit run dashboard/app.py

2. The browser will open to http://localhost:8501

3. Click "Smart Dispatch Planner" (first item in sidebar)

4. Fill in the form:
   - Source: e.g., "Pune"
   - Destination: e.g., "Mumbai"
   - Weight: e.g., 1200 lbs
   - Priority: high/medium/low
   - Delivery Date: Select from calendar

5. Click "Generate Dispatch Plan"

6. Review results in 4 tabs:
   - Summary: Key metrics
   - Truck Details: Assignment & utilization
   - Route & Costs: Complete breakdown
   - AI Insights: Recommendations

7. Download dispatch plan as JSON

METHOD 2: FASTAPI ENDPOINT
-------------------------------------------
1. Start the API:
   python backend/main.py

2. Open browser to:
   http://localhost:8000/docs

3. Find the POST /dispatch-plan endpoint

4. Click "Try it out"

5. Enter JSON body:
   {
     "source": "Pune",
     "destination": "Mumbai",
     "weight": 1200,
     "priority": "high"
   }

6. Click "Execute"

7. View complete dispatch plan in response

METHOD 3: PYTHON CODE
-------------------------------------------
from dispatch.smart_dispatcher import create_dispatch_plan

plan = create_dispatch_plan(
    source="Pune",
    destination="Mumbai",
    weight=1200,
    priority="high"
)

print(f"Truck: {plan['truck_assignment']['truck_id']}")
print(f"Cost: ${plan['cost_analysis']['final_cost']:.2f}")
