## 💡 Tips & Tricks

### Dashboard Tips:
- **Hover over charts** to see exact values
- **Click sidebar items** to switch pages quickly
- **Press 'R'** to refresh if data updates
- **Press 'C'** to clear cache if needed

### Performance Tips:
- Dashboard loads in ~3 seconds
- First load might take longer (building cache)
- Subsequent page switches are instant

### Troubleshooting:
- **JSON Error?** Run: `python fix_json_files.py`
- **Port in use?** Close other Streamlit instances
- **Slow loading?** Check Task Manager for other Python processes
